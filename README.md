# Cisco Network Design Project

## 1. Project Overview

This project was completed as part of a collaborative academic project for the Diploma in Information Technology (Communication Networks).

Our team focused on the design, planning, documentation and simulation of a computer network infrastructure using Cisco Packet Tracer.

The project demonstrates the practical application of networking principles, network topology design, device selection, technical documentation and project planning.

## 2. Project Objectives

- Design a structured network infrastructure.
- Develop physical and logical network topologies.
- Identify and select appropriate networking devices.
- Document network components and configurations.
- Simulate the proposed network using Cisco Packet Tracer.
- Plan and manage project activities using a Gantt chart.

## 3. Tools and Technologies

- Cisco Packet Tracer
- Computer networking concepts
- Network topology design
- IP addressing and network configuration
- Network infrastructure documentation

## 4. Network Design

The project includes two network design representations:

- **Physical Topology:** Illustrates the physical network layout and connections between devices.
- **Logical Topology:** Illustrates the logical organisation and communication structure of the network.

Both diagrams are included in this repository.

## 5. Network Implementation

Our team modelled and simulated the proposed network infrastructure using Cisco Packet Tracer.

The simulation file is included in this repository to allow users to explore the network design and inspect the configured devices.

## 6. Project Documentation

Supporting documentation is available in the `Documentation` folder, including:

- Technical project documentation.
- Network device cut sheet.
- Supporting network design information.

## 7. Project Planning

Project scheduling and planning documentation is available in the `Project-Planning` folder, including the Gantt chart outlining the planned activities and project timeline.
